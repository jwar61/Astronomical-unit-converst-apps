# 🌌 Astronomical Unit Converter

An interactive **Streamlit** web application for converting common **astronomical distance** and **angular measurement** units. This project is designed for astronomy students, researchers, and enthusiasts who need quick and accurate unit conversions.

---

## 📖 Overview

The **Astronomical Unit Converter** provides an easy-to-use interface for converting between several astronomical distance units and angular measurements.

The application includes:

- Distance conversions
- Angular conversions
- Interactive Streamlit interface
- NASA-inspired background image
- Input validation for non-negative values

---

##  Features

### Distance Conversions

Convert between:

- Kilometers (km)
- Astronomical Units (AU)
- Light-years (ly)
- Parsecs (pc)

Supported conversions:

- km → AU
- AU → km
- AU → Light-years
- Light-years → AU
- Light-years → Parsecs
- Parsecs → Light-years
- km → Light-years
- Light-years → km
- km → Parsecs
- Parsecs → km
- AU → Parsecs
- Parsecs → AU

---

### Angular Conversions

Convert between:

- Degrees (°)
- Arcminutes (')
- Arcseconds (")

Supported conversions:

- Degrees → Arcminutes
- Arcminutes → Degrees
- Arcminutes → Arcseconds
- Arcseconds → Arcminutes
- Degrees → Arcseconds
- Arcseconds → Degrees
